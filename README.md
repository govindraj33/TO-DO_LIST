# To-Do List Application

This is a simple To-Do List application developed in Python using Object-Oriented Programming (OOP).  

## Features
- Add tasks
- Update tasks
- Mark tasks as completed
- Remove tasks
- Persistent data storage using a file

## How to Run
1. Open the project folder in Python IDE or terminal.
2. Run the main Python file (e.g., `todo.py`).
3. Follow the on-screen instructions to manage your tasks.
